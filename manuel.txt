# FONDAMENTALS #
########################################################################
##

Cervelet is a low level program that processes a simple brain structure
The builder is a wrap manager, which wraps can build a simple brain structure

A simple brain structure is a tri-dimensionnal structure, each x-y-z position being a brain unit, named portion
Note : this may not represent a 3D brain structure, instead a plane thick structure (such as cerebral cortex), or a thick bar structure
All size_x * size_y * size_z portions are designed with 32 bytes, where all needed information are stocked for its work

The program scans all the portions from first to last in a row ; this is called a cycle
For a little i5-6400 2.7GHz processor, a 512x256x32=4Mp cervelet (128Mb) runs a cycle in 16ms

Considering a brain is 100 000 000 000 neurons,
Considering the synapses-buttons are unified in buttons-blocs
I estimate 400 000 000 000 portions are needed for a human brain simulation
... also 100 000 times actual size

With optimization, I win raise cycle time to 10ms (is around a brain rate)
With some powerfull processors, and/or in some years forward, we'll gain x10 factor (maybe more)
That means, a net of 10 000 computers will be necessary
This is not so much
That's why next step is networking (coming soon)

########################################################################
# CERVELET #
########################################################################
##

Fondamental portions are neurons and axones :
- Neurons receive impulses from upstream axones (axones act), and activates themselves at a defined level (neuron act)
- Axones (axonal-extentions) gets the activity of a unique upstream neuron, and transmits an impulse to a unique downstream neuron, via a virtual bloc of synapses
In order to get larger and asynchroneous structures, there is another type of portion :
- Segments (dendritic-segments) can play the role of upstream side neurons without auto activation : they only transmit impulses count to downstream segment/neuron
Some annex portions are designed for special purposes :
- Data source : point to get information directly from data in programs memory (loaded file content)
- Reader : reads information from a source defined in a Data source portion
- Pulseur : to give a regular beat (usually for tests)

########################################################################
# BUILDER #
########################################################################
##

Builder is a python program that aims to build and manage a wrap-pack
A pack can either represent a customizable portion, or be a customizable group of other packs
For every numeric data, you can use a formula (pre-designed or of you own)
You can build your own wrap-pack, load and save it, but always with file-name "structure.wrp" (a backup is always created)
Once your wrap-pack is ok, you can save the resulting structure always as "structure.crv" (a backup is always created)

## Keys (on windows window, not shell)

A : draw portion's type
Z : draw synapses blocks values
E : draw loadings (default)
R : draw retroactive states

U : output target's details in shell window (toggle)

H : list of commands (toggle)

V : X target +
X : X target -
C : Y target +
D/F : Y target -
Q/S : Z target & plane +
W : Z target & plane -

B : step by step mode (toggle)
N : next step

I : load from "structure.crv" - in step by step mode only
S : save to "structure.crv" - in step by step mode only (without backup)

P : Quit
