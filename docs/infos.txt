gcc -O3 -march=native -funroll-loops -fomit-frame-pointer cervelet.c -o cervelet -lgdi32

-march=native : optimiser le code pour l'architecture du processeur actuel (risque : incompatibilités)
-funroll-loops : dérouler les boucles (risque : grosse taille du binaire)
-fstrict-aliasing : optimisations basées sur les règles d'alias strictes (risque : bugs subtils)
-fomit-frame-pointer : ne pas conserver le pointeur de cadre (risque : difficulté à débugger)
-ffast-math : optimisation des calculs en virgule flottante (risque : perte de précision)
